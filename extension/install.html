Get the Óia app

To save articles, links, screenshots, images, videos, and quotes to your library, you need the Óia app on your Mac. The extension hands each item to the app, which saves it as a file you own.

Install and open the Óia app build that came with this extension before continuing.

1
Download and install the app
Build or download Óia from this project, then move it to your Applications folder.
2
Open it once
Launch Óia and choose the folder where your saved items will live. It connects to this extension automatically.
3
Save anything you want to keep
Use the Óia toolbar button and choose Save to keep the page automatically, or Save as screenshot for one long screenshot of the full scrollable page. Or right-click a page, image, video, or text selection and choose Save to Óia. The ⌃⇧S shortcut performs the same Save action.

Already installed it? Make sure you've opened the Óia app at least once, then try saving again. If you moved the app after opening it, open it once more so it can reconnect. In Firefox, use the Firefox build of the extension and allow access to the page when prompted.
